# Dark Citadel — Terraria Resource Pack

**Dark Fantasy / High-Contrast Pixel Art (Dark Mode)** для Terraria 1.4+.

Репозиторий уже является корнем resource pack: `pack.json` и `Content/` находятся на верхнем уровне. В нём реализован **Этап 1 ТЗ — проверяемый vertical slice**, а не выдан неполный набор за «полный ретекстур».

## Реализовано в 0.1.0

| Область | Результат |
|---|---|
| UI | Тёмный металлический HUD: сердца, золотые сердца, звёзды маны, а также полный набор элементов режимов **Fancy Classic** и **Horizontal Bars**. |
| Предметы | 5 железных инструментов/оружия: кирка, широкий меч, короткий меч, молот, топор. |
| Блоки | Земля (`Tiles_0`), камень (`Tiles_1`) и железная руда (`Tiles_6`). Все кадры перерисованы в исходной сетке 16×15 с шагом 18×18 px. |
| Моб | `NPC_1`: Blue Slime превращён в **Abyssal Slime**, с сохранённым двухкадровым спрайт-шитом 32×52. |
| Контроль качества | Манифест размеров, автономный валидатор RGBA PNG и скрипт сверки с извлечёнными ванильными PNG. |

Все пиксельные иллюстрации в этом репозитории оригинальны и создаются из кода `tools/build_assets.py`; ванильные текстуры Terraria в репозиторий не копируются.

## Установка

1. Скачайте архив из `release/Dark_Citadel_Phase_1.zip` **или** создайте его командой ниже.
2. Поместите ZIP без дополнительной вложенной папки в:
   `Документы/My Games/Terraria/ResourcePacks/`
3. В Terraria откройте **Workshop → Use Resource Packs**, включите **Dark Citadel**.
4. Чтобы увидеть все элементы HUD текущего этапа, в настройках интерфейса переключите набор ресурсов жизни/маны на **Fancy Classic** или **Horizontal Bars**.

> Игра сопоставляет файлы по пути, имени и размеру холста. Не меняйте имена и не масштабируйте PNG.

## Проверка и сборка

Требуется только Python 3 из стандартной поставки:

```bash
# Пересобрать оригинальные PNG и манифест
python3 tools/build_assets.py

# Проверить пути, точные размеры, RGBA 8-bit и сетки кадров
python3 tools/validate_pack.py

# Финальная сверка с PNG, извлечёнными из ТОЙ ЖЕ версии Terraria
python3 tools/validate_pack.py --vanilla /path/to/extracted/Terraria/Content/Images

# Создать устанавливаемый ZIP
python3 tools/package_pack.py
```

Результат последней команды: `release/Dark_Citadel_Phase_1.zip`. В корне этого ZIP сразу лежат `pack.json`, `icon.png` и `Content/`.
