# Dark Citadel — Style Guide

## Художественное направление

**Dark Fantasy / High-Contrast Pixel Art.** Мир строится из почти чёрных синих масс; материал считывается небольшими, очень яркими акцентами. Чёрный контур отделяет предмет от фона, а не заменяет собой объём. Каждый светлый пиксель должен обозначать грань, магический отблеск или игровой фокус.

### Визуальные правила

1. **Силуэт до деталей.** Предмет должен читаться на тёмном фоне инвентаря в масштабе 1×.
2. **Три ступени объёма.** Тень → локальный цвет → редкий блик. Не использовать сглаживание или полупрозрачные полутени на игровых спрайтах.
3. **Цвет несёт смысл.** Голубой — холодная сталь/мана; золото — редкость, интерфейс и кромка; алый — здоровье и опасность; фиолетовый — древняя магия.
4. **Сетка неприкосновенна.** Добавлять детализацию можно внутри кадра, но нельзя менять canvas, порядок кадров, stride или прозрачные отступы.
5. **Швы тайлов.** Внешняя граница каждого 16×16 tile-frame остаётся базовым цветом материала. Деталь не пересекает границу: поэтому соседние блоки не дают светлых швов.

## Требования к PNG

- PNG, **8-bit RGBA / 32-bit alpha**;
- прозрачность только там, где она присутствует в исходной текстуре;
- nearest-neighbour: не интерполировать и не экспортировать палитровый PNG;
- названия и регистр файла повторяют ванильный путь буквально;
- для каждого нового source asset внести точный canvas и frame-grid в `docs/ASSET_MANIFEST.json` до начала отрисовки.

## UI

Панели — `Void`/`Slate` с тонкой `Gold dark` обвязкой. Активный ресурс не должен полагаться только на оттенок: HP читается по алой заливке, MP — по голубой кристаллической форме. Текст интерфейса остаётся ванильным и должен иметь минимум один уровень контраста относительно панели.
